
# BIHTER'İN SON CENAZESİ

TikTok canlı yayınları için geliştirilen ücretsiz,
3D etkileşimli cenaze oyunu prototipi.

## Teknolojiler

- Three.js
- Vite
- JavaScript
- HTML
- CSS
- Vercel

## Özellikler

- 3D saray ve cenaze sahnesi
- Tabut ve karakter animasyonları
- UYAN ve GEL oylaması
- KATIL, TASIMA ve DUA komutları
- Hediye prova sistemi
- Türkçe tarayıcı seslendirmesi
- Yazılı hediye bildirimleri
- Mobil uyumlu arayüz
- Beş dakikalık maç sayacı

## Kurulum

npm install

npm run dev

## Vercel ayarları

Framework: Vite

Build Command:
npm run build

Output Directory:
dist

Install Command:
npm install

## Önemli

Bu sürüm prototiptir.

Hediye düğmeleri gerçek TikTok hediyesi değildir.
Gerçek TikTok yorum ve hediye bağlantısı henüz eklenmemiştir.

Karakter modelleri basit 3D prototiplerdir.
Fotogerçekçi modeller sonraki geliştirme aşamasında
uygun lisanslı varlıklarla eklenmelidir.

Türkçe ses kalitesi cihazdaki tarayıcı seslerine bağlıdır.

Proje ücretli API kullanmaz.
Ücretsiz servislerin kullanım limitleri olabilir.
